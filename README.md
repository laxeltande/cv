# cv
### doga_cv — A Personalized LaTeX CV Class for Technical Resumes

doga_cv is a personalized modification of the muratcan_cv LaTeX class, adapted for engineering and technical internship applications.

The class is based primarily on the work of Murat Can Karacabey, with design inspiration from Michael Pollind’s Awesome CV. This version keeps the original structure and ideas intact while introducing personal adjustments to layout, spacing, and commands to better suit my own resume needs.


## Purpose
This repository contains my general-purpose technical resume format, designed to present a broad overview of my background across:
- Software engineering
- Robotics and autonomous systems
- Embedded systems and hardware integration
- Research and academic work

I also maintain separate, more specialized resume versions (e.g., robotics-focused, software-focused, research-focused) built on top of this class, with content tailored to specific roles.

## Features
- Clean, single-page technical resume layout
- Compact section spacing suitable for internship applications
- Aligned experience entries with dates
- Simple skills layout for mixed technical backgrounds
- Custom header with links and contact information

## Usage
Clone the repository, place doga_cv.cls in the same directory as your resume .tex file, and set the document class to doga_cv. Compile using XeLaTeX or LuaLaTeX.

## Customization
The class exposes simple commands for setting name, contact information, links, and theme color. Additional customization such as spacing, fonts, and section formatting can be done directly in doga_cv.cls, which closely follows the structure of the original class.
